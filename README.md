# Rekue quality URL fixtures

Six synthetic HTML documents for the Rekue quality corpus. They contain no personal data. The source assets and expected hashes are tracked in `rekue/evaluation/assets/asset-register.jsonl`.

The three `h2-url-*.html` files are proposed, independent heldout-v2 inputs. They contain no personal data and are not approved gold or quality scores. Their byte hashes are registered in `rekue/evaluation/heldout-v2/assets/register.jsonl`; GitHub Pages serves them only after this change reaches the configured publishing branch.
